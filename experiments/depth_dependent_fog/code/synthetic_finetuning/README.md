# Original depth-dependent GitHub prototype

This folder preserves the code introduced by the merged depth-dependent fog
update, including the spatial-fog GUI, ZoeDepth preprocessing, generator, and
NAFNet training script.

The validated checkpoint release used the matched benchmark path in
`../validated_benchmark/`, which records the exact one-epoch / 2,600-update
configuration. Use that workflow for reproduction. This prototype remains
available for generator development and GUI-based exploration.
